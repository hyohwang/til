# Dashboard home: numbers that match the lists

学んだ日：2026-11-16

## Key points (EN)
- The number on a home tile and the count in the list it opens must use **the same filter**, so they always match.
- Show the active filter as a removable chip above the list.
- Consider keeping the home screen to current numbers and moving trends (e.g. change from yesterday) to a report page.
- Separate "waiting for the customer" from "reply received" (e.g. "Waiting for customer" / "Customer replied").
- Show only the top N rows on the home screen and link to the full list, instead of scrolling inside a table.

## 要点（日本語）
- ホームのタイルの数字と、押して開く一覧の件数は、**同じ条件**で数えて必ず一致させる
- 一覧の上に、今かかっている条件を札（チップ）で見せ、× で外せるようにする
- ホームは「今の数」に絞り、前日との比較のような増減は報告の画面に置く、という分け方もある
- 「顧客の返事を待っている」と「返事が届いた」を別の状態にする（例：「顧客の回答待ち」「顧客から回答あり」）
- ホームの表は上位の件数だけにし、残りは一覧へのリンクにする（表の中でスクロールさせない）
