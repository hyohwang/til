# Layers of an AI system

学んだ日：2026-11-17

## Key points (EN)
- An AI system can be described in layers:
  1. **Application** — the interface users interact with (chat, business screens)
  2. **Agent** — plans the steps and calls tools, APIs, and other systems
  3. **AI model** — the model (typically an LLM) that generates responses
  4. **Data** — documents and business data the AI reads (search indexes, data catalogs)
- **Governance** (access rights, logs, rules) is not one layer. It applies across all layers.

## 要点（日本語）
- AI のシステムは、層に分けて説明できる
  1. **アプリ**：使う人が触る画面（チャット、業務の画面）
  2. **エージェント**：手順を決め、道具やほかのシステムを呼び出す
  3. **AI モデル**：答えを作るモデル（多くは LLM＝大規模言語モデル）
  4. **データ**：AI が読む資料と業務のデータ（検索のための索引、データのカタログ）
- **ガバナンス**（権限・記録・ルール）は、どれか1つの層ではなく、全部の層にかかる

## つまずいた点
- 層の名前や切り方は、製品や人によって違う。話す相手の定義と合っているかを確かめる
